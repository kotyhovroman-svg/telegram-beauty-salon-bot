# 💅 Telegram-бот записи в салон красоты (Nail Studio)

Бот для автоматизации записи клиентов в салон красоты с интеграцией в Google Таблицы и уведомлениями администратору.

## 🚀 Функционал
- Интерактивный выбор услуг и свободного времени через Inline-меню
- Автоматическая передача данных в Google Sheets (gspread)
- Мгновенное уведомление администратора в Telegram при новой записи
- Сбор контактов пользователя

## 🛠 Технологии
- Python 3.10+
- `pyTelegramBotAPI`
- `gspread` & Google Sheets API
- `python-dotenv`
